# Aegis 普通用户使用手册：CORE MODULES

本文面向已拥有可登录 Aegis 账号的普通用户，说明侧栏 **CORE MODULES** 分组中的基础功能。管理员同样可以使用本手册中的功能，但管理员专属功能请参阅《Aegis 管理员使用手册：CONTROL》。

适用版本：Aegis `v0.2.3`。

## 1. 适用人群与权限范围

**面向人群**

- 安全运营、事件响应、分析研判、合规协作等日常使用 Aegis 的业务用户；
- 已由管理员启用的普通账号；
- 需要查看中枢运行态、在 Chat 中发起分析、维护个人提示词模板的用户。

**可见菜单**

```text
CORE MODULES
├─ Overview（中控概览）
├─ Aegis Chat（智能安全对话）
└─ User Profile（用户偏好）
   └─ Prompt Template（提示词模板）
```

普通用户不能访问 **CONTROL** 分组。即使直接输入管理员页面地址，系统也会提示需要管理员权限并回到 Overview。

## 2. 开始前：注册、登录与账户操作

### 2.1 注册账号

| 项目 | 内容 |
| --- | --- |
| 面向人群 | 尚无 Aegis 账号的用户 |
| 功能 | 提交用户名、密码和邮箱，申请一个普通账号 |
| 功能路径 | 登录页 → **Create Account** |

**使用方法**

1. 打开 Aegis 登录页。
2. 选择 **Create Account**。
3. 填写用户名、密码和邮箱并提交。
4. 等待管理员在 **CONTROL → User Management** 中将账号状态启用。
5. 收到启用通知后，返回登录页使用用户名和密码登录。

**注意事项**

- 新注册账号默认是停用状态，未启用前无法登录；这不是注册失败。
- 请使用可识别的工作邮箱，方便管理员核对申请人身份。
- 不要与他人共享账号或密码。

### 2.2 登录、修改密码与退出

| 项目 | 内容 |
| --- | --- |
| 面向人群 | 已启用账号的用户 |
| 功能 | 建立登录会话、修改自己的密码、安全退出 |
| 功能路径 | 登录页 → **Sign In**；登录后右上角 **User Menu** → **Change Password** / **Sign Out** |

**登录方法**

1. 在 **Username** 和 **Password** 中输入凭据。
2. 选择 **Sign In**。
3. 登录成功后默认进入 **Overview**。

**修改密码方法**

1. 选择右上角用户名区域，打开 **User Menu**。
2. 选择 **Change Password**。
3. 输入当前密码和新密码。
4. 选择 **Update Password**。

**退出方法**

1. 打开右上角 **User Menu**。
2. 选择 **Sign Out**。

**注意事项**

- 修改密码需要先验证当前密码；请避免使用与其他系统重复的弱密码。
- 在共享电脑或临时终端上完成工作后务必退出。
- 若会话过期，Aegis 会要求重新登录；请不要通过刷新页面绕过登录提示。

## 3. Overview（中控概览）

| 项目 | 内容 |
| --- | --- |
| 面向人群 | 所有已登录用户 |
| 功能 | 查看 Aegis 整体运行概况、近 7 天委派指标、拓扑关系和可见 Agent 索引 |
| 功能路径 | **CORE MODULES → Overview（中控概览）** |

### 3.1 页面信息说明

| 区域 | 作用 | 建议用法 |
| --- | --- | --- |
| 页头 `LIVE_SYNC` | 显示控制台与后端的同步状态 | 正常应为 `CONNECTED`；出现 `DEGRADED` 时先检查网络或刷新页面 |
| 关键指标 | 显示最近 7 天执行 Agent 数、来源平台数、活跃用户数、委派量与成功率 | 用于判断近期调用规模和稳定性，不作为单条事件处置结论 |
| Aegis Orchestration Topology | 展示中枢、Agent Ring 与依赖星图 | 悬停或聚焦节点查看说明；用于理解能力分层与依赖关系 |
| Delegation Health (7D) | 汇总成功、失败、授权拒绝数量及成功率 | 发现失败或拒绝升高时，将时间范围、Agent 名称交给管理员核查 |
| Agent Index | 显示当前可见 Agent 的名称、状态、描述和任务信息 | 使用搜索框和状态筛选快速定位 Agent |

### 3.2 常用操作

**查看某类 Agent**

1. 进入 **Overview**。
2. 在 **Agent Index** 的搜索框输入 Agent 名称或描述关键词。
3. 在状态下拉框选择 `Active`、`Idle` 或 `Offline`，必要时选择 `All Status` 清除筛选。
4. 查看卡片中的状态、描述与任务信息。

**从概览进入会话**

1. 在页面顶部选择 **启动智能对话**。
2. 系统进入 Aegis Chat；后续操作见下一节。

**注意事项**

- Overview 反映的是已记录的运行态和统计窗口，不保证远程 Agent 此刻一定可接收请求。
- `planned` 或无运行数据的拓扑节点可能是设计基线，并不代表已在 A2A 注册表中启用。
- Agent 运行状态、地址和路由策略由管理员维护；普通用户只读查看，不应据此自行假设授权范围。

## 4. Aegis Chat（智能安全对话）

| 项目 | 内容 |
| --- | --- |
| 面向人群 | 所有已登录用户 |
| 功能 | 创建会话、发送分析请求、查看执行链路、使用个人模板，以及查看当前 A2A Agent 上下文 |
| 功能路径 | **CORE MODULES → Aegis Chat（智能安全对话）** |

### 4.1 创建与管理会话

**创建会话**

1. 在左侧 **CENTRAL ARCHIVE** 顶部选择加号图标（悬停提示为 `New chat thread`，无障碍名称为“新建对话”）。
2. 在底部输入框填写任务描述。
3. 选择 **发送**，或在单行输入框中按 Enter。
4. 首次发送后，系统建立该会话的实时通道并显示处理状态。

**切换、删除与清空本地会话**

1. 在左侧会话列表选择某一会话可切换上下文。
2. 将鼠标移到会话条目上，选择删除图标可删除该本地会话记录。
3. 选择底部 **清空运行环境缓存** 可清空当前浏览器保存的本地聊天会话。

**注意事项**

- “清空运行环境缓存”和删除会话会删除本地可见历史；执行前先保存需要留存的结论或证据。
- 新建会话会清空当前草稿。若已有未发送内容，请先复制保存。
- 左侧的未读或审批/澄清标记表示会话需要关注；请先进入对应会话处理。

### 4.2 发送分析请求与处理交互

**推荐输入方式**

请求应尽量包含背景、目标、已知证据和期望输出。例如：

```text
请评估以下可疑登录事件：时间、源 IP、账号、目标系统如下……
请输出：风险等级、关键证据、下一步调查项和需要人工批准的动作。
```

**发送方法**

1. 在底部输入框填写内容。
2. 选择 **发送**。
3. 需要多行编辑时，选择输入框右侧的展开图标；展开状态下使用 `Ctrl/Cmd + Enter` 发送。
4. 在消息区域查看主 Agent 回复、委派事件、工具活动和编排链路。

**授权与澄清**

- 出现 **Approval Required** 时，仔细阅读动作描述和命令，再按实际权限选择 `Allow Once`、`Session`、`Always` 或 `Deny`。
- 出现 **Clarify Required** 时，可选择预设选项、选择 `Other` 后在输入框补充说明，或直接填写所需答案。

**注意事项**

- 仅在理解影响范围并具备相应授权时才允许高风险动作；不确定时选择 `Deny` 或联系管理员。
- `Session` / `Always` 可能扩大后续动作的许可范围，尤其要谨慎使用。
- 输入的内容会作为本次任务上下文发送给后端和可能被授权的远程 Agent；不要粘贴无关密码、长期密钥或超出任务需要的个人信息。
- **Attach references** 图标目前仅为界面入口，当前版本不提供文件上传或附件提交功能。

### 4.3 查看执行链路与复制结果

**功能路径**：**Aegis Chat → 顶部 Toggle delegate tool messages / 消息卡片**。

**使用方法**

1. 在 Chat 页右上选择 **Toggle delegate tool messages**，决定是否显示委派工具消息。
2. 对包含 **Orchestration Chain** 的消息，查看各步骤的状态和时间。
3. 对工具活动选择 **SHOW DETAILS** / **HIDE DETAILS** 查看参数摘要。
4. 选择任一消息右下角的复制图标，将该消息或工具摘要复制到剪贴板。

**注意事项**

- 工具参数和结果摘要可能包含业务或安全上下文；复制到外部系统前请遵守组织的数据分级和脱敏规则。
- `DELEGATE TOOLS OFF` 只影响页面显示，不会停止远程任务或改变授权策略。

### 4.4 使用个人 Prompt Template

| 项目 | 内容 |
| --- | --- |
| 功能 | 从个人模板库快速追加分析提示词到当前草稿 |
| 功能路径 | **Aegis Chat → 输入框右侧“模版”图标** |

**使用方法**

1. 在 Chat 输入框中先填写已有草稿（可选）。
2. 选择 **模版** 图标，打开 **USER PROMPT LIBRARY** 抽屉。
3. 按标签浏览模板，选择一个模板条目。
4. 系统将模板的 Prompt 追加到当前草稿末尾，并关闭抽屉。
5. 检查和修改草稿后，再选择 **发送**。

**注意事项**

- 选择模板不会自动发送消息。
- 模板按当前登录账号隔离；你看不到、也不能修改其他用户的模板。
- 模板只是草稿辅助，不会自动改变系统提示词、路由规则或远程 Agent 权限。

### 4.5 浏览当前 A2A Agents

| 项目 | 内容 |
| --- | --- |
| 功能 | 查看当前 A2A 注册表的活跃 Agent、可用性、描述与能力 |
| 功能路径 | **Aegis Chat → CENTRAL ARCHIVE 顶部 Agents 图标** |

**使用方法**

1. 选择 **Agents** 图标，打开 **A2A AGENT CONTEXT** 悬浮窗。
2. 在卡片中查看 Agent 名称、`available` 状态、描述、运行状态和能力数量。
3. 选择卡片进入详情，查看 A2A URL、完整描述、错误信息（如有）和能力清单。
4. 使用 **Back to agents** 返回卡片列表；使用刷新图标请求新的 A2A 上下文快照；使用关闭图标退出。

**注意事项**

- 打开或刷新此窗口不会向当前聊天会话发送 `/a2a`，也不会发送任何聊天消息。
- 首次打开会读取实时快照，随后打开会使用后端进程缓存；刷新失败时会保留上一次成功结果，并提示该结果可能过期。
- 显示 `unavailable` 或错误信息通常表示 Card 读取或远端连通性异常。请记录 Agent 名称与错误信息后联系管理员，不要自行修改远端地址。

## 5. User Profile → Prompt Template（提示词模板）

| 项目 | 内容 |
| --- | --- |
| 面向人群 | 所有已登录用户 |
| 功能 | 创建、浏览、编辑和删除仅属于当前账号的可复用提示词模板 |
| 功能路径 | **CORE MODULES → User Profile（默认折叠）→ Prompt Template** |

### 5.1 打开页面

1. 在侧栏 **CORE MODULES** 中选择 **User Profile（用户偏好）**。
2. 该分组默认折叠；选择后展开子菜单。
3. 选择 **Prompt Template（提示词模板）**。
4. 页面以列表方式显示当前账号的 `Tag`、描述、更新时间和管理操作。

### 5.2 新建模板

1. 选择 **New Template**（或页面中的新增模板按钮）。
2. 在悬浮窗口填写：
   - **Tag**：用于分类和 Chat 抽屉分组，例如“事件调查”“邮件研判”；
   - **Description**：可选的简短说明，帮助自己在列表中识别；
   - **Prompt**：会追加到 Chat 草稿的实际内容。
3. 选择保存。

**注意事项**

- `Tag` 与 `Prompt` 必填，且不能只包含空格；`Description` 可留空。
- 同一账号允许使用重复 Tag；Tag 的作用是分组，不是唯一标识。
- Prompt 应保持可复用和目标明确，避免嵌入一次性机密、令牌或个人敏感信息。

### 5.3 浏览、编辑与删除模板

**浏览**

1. 在模板列表选择浏览/查看操作。
2. 在悬浮窗口查看完整 Description、Prompt、创建时间与更新时间。

**编辑**

1. 在对应模板行选择编辑。
2. 修改 Tag、Description 或 Prompt。
3. 保存后，更新时间会变更。

**删除**

1. 在对应模板行选择删除。
2. 阅读二次确认提示。
3. 确认后删除。

**注意事项**

- 删除不可恢复；若模板是团队常用内容，请先复制到组织认可的知识库再删除。
- 已经追加到 Chat 草稿中的文本不会因后续编辑或删除模板而自动更新。
- 当页面出现加载或错误提示时，先刷新页面或重新登录；不要连续重复提交同一新增操作。

## 6. 普通用户日常检查清单

- [ ] 使用已启用的个人账号登录；
- [ ] 在 Overview 确认整体状态无明显异常；
- [ ] 新建独立会话处理独立事件，避免混用无关上下文；
- [ ] 在发送前复核 Prompt Template 追加后的完整草稿；
- [ ] 遇到授权或澄清请求时按实际权限处理；
- [ ] 遇到 Agent 不可用、会话错误或权限拒绝时，保留时间、会话和错误信息并联系管理员；
- [ ] 完成工作后退出 Aegis。
